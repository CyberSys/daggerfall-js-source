# Patch Notes: Plainer menus

## Overhaul menu
- **New descriptions for every look**, written by Mac: Classic and Enhanced sound, Classic and Enhanced UI, and GrimoireUI.

## Enhanced UI
- The colour setting is now called **UI colour**, and the run setting **Left stick run**.
- In Controller bindings, a button with more than one use shows them with a slash, like **Draw / sheathe**: **Activate / Select**, **Inventory / Back**, and the d-pad's tap and hold.

## Features
- **Every description rewritten in plain words.** Each one says what the feature does, what turning it off does, and what changes online. Technical terms, version numbers and long lists are gone.
- Daggerfall Unity's own options now end with their default, for example "Off by default in Daggerfall Unity."

## Online
- The Online page explains the shared world in plain sentences, and a setting that is fixed online says why in one short line.
