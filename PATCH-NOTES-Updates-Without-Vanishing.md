# Patch Notes: Updates without vanishing

## Desktop app (Windows)
- **Updating no longer leaves Daggerfall Online missing.** The app used to install as more than 18,000 separate files. An update removed every one of them, then put the new ones back one at a time, with no window on screen. While it ran, the game's folder was empty and its shortcut went nowhere. If you clicked the shortcut then, Windows offered to delete it. If you restarted the PC then, the app was gone. The game's files are now packed into a single archive, so the app installs as fewer than a hundred files. An update now swaps a handful of files instead of thousands.
- **The next update is the last slow one.** The version you have now removes its old files the old way, one at a time. After that, updates are quick. If Daggerfall Online seems to have vanished during that update, the update is still running: give it time to finish before reinstalling.
- Your saves, settings and game files are kept, as they always were. They are stored outside the app's folder.
- The portable Windows build no longer unpacks those 18,000 files every time you launch it.
