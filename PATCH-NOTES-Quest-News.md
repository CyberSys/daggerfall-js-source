# Patch Notes: Quest news

## Quests (Enhanced interface)
- **Your journal tells you when it changes.** A notice slides in at the right edge when a quest begins, when its journal gains an entry, when it has less than a day left, and when it is completed or ends. Each one gives the quest's title and one line: the start of the new journal entry, or the time left.
- **One notice per quest.** If a quest changes twice in quick succession, you get one notice with the latest news, not a stack of them.
- **Read aloud.** The notices go through the same notification panel as every other enhanced message, so a screen reader announces them.
- **It waits for you.** A notice's time only runs while the HUD is showing. News that arrives as you open a window is still there when you close it.
- **Your choice.** Turn it off under Features, Interface, "Quest news". With it off, the journal changes silently, as it does in Daggerfall.
- The quest's own messages and popups are unchanged, and the Classic interface is unchanged.
