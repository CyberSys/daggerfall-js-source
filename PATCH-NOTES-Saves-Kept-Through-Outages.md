# Patch Notes: Saves kept through outages

## Online
- **An outage no longer costs your online progress.** Your online character saves to the server every two minutes, and when you leave. If the server could not be reached, that save used to live only in the open game page. Closing, reloading or leaving to the menu before the server came back lost everything since the last save it took. Every online save is now also kept on your device until the server takes it. The next time you play that character, you carry on from it, and the game tells you so.
- **Closing the game no longer loses your last minutes.** When you closed the page, the game sometimes gave up your character before its final save reached the server, and that save was refused. The kept copy now covers this too.
- A kept save is only used if nothing newer reached the server since, from another device, a trade or a purchase. Otherwise the server's save is played and the kept copy is discarded.
